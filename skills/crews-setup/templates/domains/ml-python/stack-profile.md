## 실행 모델

이 도메인의 코드는 **설정 파일이 주도하는 단계 파이프라인**이다. 명령줄 인자가 아니라
`configs/*.yaml`이 진실이고, 단계는 이전 단계의 산출물을 입력으로 받는다.

- **설정을 바꾸는 것이 코드를 바꾸는 것과 같은 무게**다. 하이퍼파라미터·경로·클래스 목록은
  전부 설정에 있고, 그 변경은 산출물을 바꾼다.
- 파이프라인 단계를 건너뛰면 **오래된 중간 산출물이 조용히 재사용된다.**
  실패는 예외가 아니라 "이상하게 좋은/나쁜 지표"로 나타난다.
- `Makefile`(또는 그에 상당하는 진입점)이 조작 인터페이스다. 하위 스크립트를 직접 호출하면
  기본 변수·가드가 빠진다 — 측정값의 타깃 표를 통해 실행한다.

## 경로 규약

| 유형 | 위치 |
|------|------|
| 패키지 코드 | `src/{패키지}/` (src 레이아웃) 또는 `{패키지}/` |
| 단계 구현 · CLI | 패키지의 `cli.py` / `__main__.py` |
| 보조 스크립트 | `scripts/*.py` — 파이프라인 본체가 아닌 분석·감사·리뷰 도구 |
| 설정 | `configs/*.yaml`, `configs/*.json` |
| 원본 데이터 | `data/raw/` |
| 전처리 데이터 | `data/prepared/` |
| 산출물 | `artifacts/` (내부 하위: 변환 포맷·리포트·실행 기록) |
| 학습 실행 기록 | `runs/` |
| 탐색용 노트북 | `notebooks/` |
| 회고·설계 문서 | `docs/`, `docs/retrospectives/` |

## 주요 규칙

- **데이터·산출물·모델 바이너리는 커밋하지 않는다.** 커밋 대상은 설정 · 코드 · 노트북 ·
  산출물 **매니페스트**(리포트 JSON 등)다. 측정값의 gitignore 열이 `X`인 디렉토리가 있으면 먼저 고친다.
- **재현성 3요소를 함께 기록한다**: 설정 파일 · 데이터셋 버전 · seed. 하나라도 빠지면
  "그때 그 결과"를 다시 만들 수 없고, 비교 실험의 결론이 무의미해진다.
- 실행 이름(run name)을 재사용하지 않는다 — 같은 이름은 이전 실행 산출물을 덮거나 옆에 쌓여
  나중에 어느 것이 무엇인지 알 수 없게 된다.
- 지표는 **어느 데이터 분할에서 나온 값인지**와 함께 말한다. 학습 분할 지표를 성능으로 보고하지 않는다.
- 노트북에서 검증된 로직은 패키지로 옮긴다. 노트북은 탐색 기록이고 실행 경로가 아니다.
- 자격증명(데이터셋 API 키 등)은 `.env`에 두고 커밋하지 않는다. 설정 파일에 키를 적지 않는다.

## 고위험 영역

여기에 해당하는 변경은 Quick Plan 선행 대상이고, 검증에서 자동 HIGH다.

- **클래스 목록의 순서와 개수** — 다운스트림(추론 서버·기기 런타임)과의 계약이다.
  순서를 바꾸면 코드는 통과하고 예측 라벨만 조용히 어긋난다
- **모델 변환·내보내기 옵션** (opset, batch, dynamic, simplify, NMS 포함 여부) —
  컴파일러·런타임 제약과 묶여 있어, 여기서 통과한 것이 기기에서 실패할 수 있다
- **데이터셋 교체·버전 상승** — 지표 변화의 원인이 코드인지 데이터인지 구분 불가능해진다
- **연산 장치 변경** (cpu / mps / cuda) — 성능뿐 아니라 수치 결과가 달라진다
- **전처리·정규화·입력 해상도** — 학습과 추론이 어긋나면 학습 지표만 좋아진다
- `data/prepared/` 재생성 로직 — 라벨 매핑 오류는 지표가 아니라 예측 내용에서만 드러난다
- 검증 게이트 임계값(설정에 있는 최소 검출 수·비율 등) — 낮추면 실패가 통과로 바뀐다

## 검증의 한계 (정책)

**학습 로그의 지표는 검증이 아니다.** 로그가 증명하는 것은 "학습이 돌았다"뿐이다.

- 지표 개선을 `[실행 확인]`으로 보고하려면 **held-out 데이터에서 나온 수치**와 그 명령을 함께 남긴다.
- 변환된 모델(런타임 포맷)의 동등성은 **원본과 같은 입력으로 비교**해야 확인된다 —
  변환 성공 로그는 `[정적 확인]`이다.
- 기기·서버에서의 동작은 이 레포에서 확인할 수 없다 → `[미검증]`으로 남기고 검증 절차를 기록한다.
- 지표를 비교할 때 **비교 대상 실행의 설정 차이를 먼저 진술**한다. 차이를 모르면 비교가 아니다.
