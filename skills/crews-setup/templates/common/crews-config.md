# Claude Agent Crews 프로젝트 설정

`/crews-setup`이 처음 한 번 생성한다. **프로젝트 소유** — 재설치 시 보존되고 커밋 대상이다.
**이 파일은 손으로 편집하는 유일한 생성물이다.**

스택·경로·고위험 영역은 `.claude/crews/stack-profile.md`,
실행·검증·배포는 `.claude/crews/run-profile.md`가 진실 공급원이다. 여기 중복 기술하지 않는다.

## 프로젝트 메타

- 도메인: (설치 시 채워짐)
- 응답 언어: ko
- 커밋 규약: 자유
- 제품 앵커: (없음) ← 멀티레포 단일 제품이면 앵커 레포의 상대 경로 (예: `../hailo-front`)

## 커스텀 룰

이 프로젝트에만 적용할 제약을 여기 쓴다. 도메인 전체에 해당하는 규칙이라면
여기가 아니라 `claude-agent-crews` 레포의 도메인 stack-profile에 올린다(그래야 다른 레포에도 간다).

- (없음)

## 검증 토글

- 빌드 검사: **on**
- 린트: **off**
- 테스트: **auto** (테스트가 존재하면 실행)

> 토글은 "무엇을 실행할지"만 정한다. **실행 결과 없이 `[실행 확인]`을 주장할 수 없다**는 규칙은
> 토글과 무관하게 유효하다 (`crews-routing.md` 참조).
