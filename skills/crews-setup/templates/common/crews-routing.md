# Claude Agent Crews 라우팅

`/crews-setup`이 생성한다. **템플릿 소유** — 재설치 시 덮어써지고 gitignore된다.
이 파일은 push 위치(세션 시작 시 로드)다. **지식이 아니라 진입 규칙만 담는다.**

## 로드 순서

코드를 변경하거나 실행·배포하는 요청을 받으면, 작업 전에 아래를 Read한다.

1. `.claude/crews/crews-config.md` — 커스텀 룰과 검증 토글
2. `.claude/crews/stack-profile.md` — 경로·규약·고위험 영역
3. `.claude/crews/run-profile.md` — 실행·검증·배포가 관련될 때
4. `AGENTS.md` · `docs/` — 존재하고 관련되면

없는 파일은 무시한다. 단순 질문·읽기 확인에는 이 순서를 강제하지 않는다.

## 고위험 영역을 건드릴 때만 Quick Plan

`stack-profile.md`의 "고위험 영역" 또는 `run-profile.md`의 "비가역 단계"에 해당하는 변경이면,
파일을 고치기 전에 아래를 출력한다.

```text
Quick Plan
- 대상:
- 변경:
- 검증 방법:   ← run-profile.md의 "검증 경로"에서 인용
- 되돌리기:
```

그 밖의 변경에는 요구하지 않는다. **트리거는 라인 수가 아니라 프로파일에서 유도된다** —
"몇 줄인가"는 위험과 무관하고, 예외 목록만 자라게 한다.

## 검증 주장 라벨

검증 결과를 보고할 때 모든 주장에 라벨을 붙인다.

- `[실행 확인]` — 실제로 실행하고 관측한 것. 명령과 출력 근거를 함께 남긴다
- `[정적 확인]` — 코드를 읽어 판단한 것. `file:line` 근거를 남긴다
- `[미검증]` — 확인하지 못한 것. **사유와 사람이 할 절차를 남긴다**

라벨 없는 "동작할 것으로 보입니다"는 `[미검증]`이다. 실기기가 없으면 `[미검증]`이 정상이며,
그것을 숨기는 것이 결함이다.

## 모르면 멈춘다

추측으로 채우지 않는다. 아래 상황에서는 현황 + 선택지를 제시하고 멈춘다.

- 프로파일에 없는 경로·명령·보드가 필요할 때 (프로파일을 갱신할 기회다)
- 관측 근거 없이 원인을 단정해야 할 때
- 요청 범위가 고위험 영역·비가역 단계를 포함할 때
